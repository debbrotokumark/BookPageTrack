# 📚 PageNest — Personal Reading Tracker

একটি সম্পূর্ণ **Offline-friendly Personal Library ও Reading Progress Tracker**। কোনো Login, Backend, Database বা API লাগে না — সব ডেটা আপনার নিজের ব্রাউজারের `localStorage`-এ থাকে।

বইয়ের পৃষ্ঠা ধারাবাহিকভাবে না পড়লেও PageNest ঠিক ঠিক হিসাব রাখে: কোন পৃষ্ঠা পড়া হয়েছে, কোনগুলো বাকি, আর কত দিনে কতটুকু পড়া হলো।

**🔗 Live Demo:** `[https://debbrotokumark.github.io/BookPageTrack/]`


---

## ✨ Features

### 📖 Library
- বই **যোগ, সম্পাদনা ও মুছে ফেলা** (নাম, লেখক, বিভাগ, শুরুর তারিখ, মোট পৃষ্ঠা, টার্গেট তারিখ, নোট)
- নাম/লেখক দিয়ে **Search** এবং বিভাগ অনুযায়ী **Filter**
- প্রতিটি বইয়ের কার্ডে Progress bar

### 🎯 Random Page Reading
- যেকোনো পৃষ্ঠা বা Range লিখে পড়া হিসেবে মার্ক করুন, যেমন `25-31, 40, 65-70`
- বাংলা (`২৫-৩১`) ও ইংরেজি (`25-31`) দুই ধরনের সংখ্যাই কাজ করে
- একই পৃষ্ঠা আবার পড়লে মোট সংখ্যা দ্বিগুণ হয় না
- ভুল মার্ক হলে **"পড়া হয়নি"** বাটনে ফেরানো যায়

### 🗺️ Page Map
- বইয়ের প্রতিটি পৃষ্ঠা একটি ছোট ঘর, এক নজরে পুরো বইয়ের অবস্থা
- যেকোনো ঘরে ক্লিক করলে সেই পৃষ্ঠা পড়া/না-পড়া Toggle হয়
- বুকমার্ক করা পৃষ্ঠা সোনালি রঙে দেখায়

### 🔎 Unread Page Finder
- না-পড়া পৃষ্ঠা Range আকারে দেখায়, যেমন `২১–৪৯, ৬১–৯৯, ১১১–৩০০`

### 🔖 Bookmark, Target, Quotes
- **Bookmark:** পৃষ্ঠা নম্বর ও ছোট নোট সহ
- **Target:** চ্যাপ্টার বা টপিকের লক্ষ্য, তারিখ ও সম্পন্ন চেকবক্স (সময় পেরোলে লাল হয়)
- **Quotes & Thoughts:** গুরুত্বপূর্ণ লাইন ও নিজের চিন্তা, পৃষ্ঠা নম্বর সহ

### 📊 Habit System
- **Daily Goal:** প্রতিদিন কত পৃষ্ঠা পড়বেন তা ঠিক করা যায়
- **Reading Streak:** টানা কত দিন পড়েছেন
- **Reading Calendar:** কোন দিনে কত পৃষ্ঠা পড়েছেন, লক্ষ্যের কাছাকাছি দিনের ঘর গাঢ় দেখায়
- **Estimated Finish Date:** গড় গতি দেখে বই শেষ হওয়ার সম্ভাব্য তারিখ
- **Analytics:** মাসভিত্তিক পড়া, বিভাগ অনুযায়ী পড়া, কোন বইয়ে বেশি দিন লেগেছে, গত ৭ ও ৩০ দিনের মোট

### 💾 Data & Backup
- ডেটা ব্রাউজারে সেভ থাকে, ট্যাব বা কম্পিউটার বন্ধ করলেও হারায় না
- **Export:** JSON ব্যাকআপ ডাউনলোড
- **Import (Merge):** আগের ডেটা না মুছে নতুন ডেটা মিলিয়ে যুক্ত করে
- ডার্ক মোড (সিস্টেম সেটিং অনুযায়ী) ও মোবাইল-ফ্রেন্ডলি ডিজাইন

## 🚀 GitHub Pages-এ Host করার নিয়ম

প্রজেক্টটি একটি মাত্র `index.html` ফাইল, তাই Hosting খুব সহজ।

1. GitHub-এ নতুন Repository খুলুন (নাম: `PageNest`)
2. `index.html` ও `README.md` Upload করুন
3. **Settings → Pages** এ যান
4. **Build and deployment** থেকে **Deploy from a branch** বেছে নিন
5. Branch: `main`, Folder: `/ (root)` দিয়ে **Save** করুন
6. কিছুক্ষণ পর সাইট `https://YOUR-USERNAME.github.io/PageNest/` এ চালু হবে

### নিজের কম্পিউটারে চালানো
কিছুই install করতে হবে না। `index.html` ফাইলটি ডাবল ক্লিক করে ব্রাউজারে খুলুন।

## 🧭 কীভাবে ব্যবহার করবেন

1. **লাইব্রেরি** ট্যাবে **+ নতুন বই** চেপে বইয়ের তথ্য দিন
2. বইয়ের কার্ডে ক্লিক করে ভেতরে যান
3. "যে পৃষ্ঠাগুলো পড়লেন" ঘরে Range লিখে **পড়া হয়েছে** চাপুন
4. Page Map-এ পড়া ও না-পড়া অংশ দেখুন
5. বুকমার্ক, টার্গেট ও উক্তি যোগ করুন
6. **ক্যালেন্ডার** ও **অ্যানালিটিক্স** ট্যাবে নিজের অভ্যাস দেখুন
7. **ব্যাকআপ ও সেটিং** ট্যাব থেকে দৈনিক লক্ষ্য বদলান ও ব্যাকআপ নিন

### Range লেখার উদাহরণ

| ইনপুট | অর্থ |
|---|---|
| `30` | শুধু ৩০ নম্বর পৃষ্ঠা |
| `25-31` | ২৫ থেকে ৩১ পর্যন্ত |
| `১-২০, ৫০-৬০, ১০০` | একসাথে একাধিক Range |

### উদাহরণ
৩০০ পৃষ্ঠার বইয়ে `1-20, 50-60, 100-110` পড়লে দেখাবে:

```
পড়া হয়েছে: ৪২ পৃষ্ঠা (১৪%)
না-পড়া:    ২১–৪৯, ৬১–৯৯, ১১১–৩০০
```

## 🛠️ Tech Stack

- HTML5, CSS3, Vanilla JavaScript (কোনো Framework বা Build step নেই)
- Canvas API (Page Map)
- `localStorage` (ডেটা সংরক্ষণ)
- Google Fonts: Hind Siliguri (অফলাইনে সিস্টেম ফন্টে fallback করে)

## 🧾 Backup ফাইলের গঠন

```json
{
  "goal": 20,
  "books": [
    {
      "id": "unique-id",
      "name": "বইয়ের নাম",
      "author": "লেখক",
      "cat": "বিভাগ",
      "start": "2026-11-02",
      "target": "2026-12-31",
      "total": 300,
      "notes": "",
      "r": [[1, 20], [50, 60]],
      "log": { "2026-11-02": 20 },
      "bm": [{ "id": "…", "p": 55, "t": "গুরুত্বপূর্ণ" }],
      "tg": [{ "id": "…", "t": "চ্যাপ্টার ৩", "d": "2026-11-20", "done": false }],
      "qt": [{ "id": "…", "t": "উক্তি", "p": 42 }]
    }
  ]
}
```

`r` হলো পড়া পৃষ্ঠার Range, `log` হলো প্রতিদিন নতুন কত পৃষ্ঠা পড়া হয়েছে।

## ⚠️ জরুরি কথা

- ডেটা **শুধু ওই ব্রাউজার ও ডিভাইসে** থাকে। অন্য ল্যাপটপ বা অন্য ব্রাউজারে নিজে থেকে পাওয়া যাবে না।
- Browser Data বা Site Data Clear করলে ডেটা মুছে যেতে পারে। তাই নিয়মিত **Export** করে ব্যাকআপ রাখুন।
- সাইটের ডোমেইন বদলালে (যেমন কাস্টম ডোমেইন) ডেটা আলাদা হয়ে যায়। আগে Export, পরে নতুন ডোমেইনে Import করুন।
- Private/Incognito উইন্ডোতে ট্যাব বন্ধ করলে ডেটা থাকে না।
